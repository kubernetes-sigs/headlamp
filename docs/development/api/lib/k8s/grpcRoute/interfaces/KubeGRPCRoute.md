# Interface: KubeGRPCRoute

Defined in: [lib/k8s/grpcRoute.ts:69](https://github.com/kehach07/headlamp/blob/7b4a853c98ea719589ddb64289f86ea94e08b877/frontend/src/lib/k8s/grpcRoute.ts#L69)

GRPCRoute is a Gateway API type for specifying routing behavior of gRPC requests from a Gateway listener to an API object, i.e. Service.

## See

 - [https://gateway-api.sigs.k8s.io/reference/api-spec/main/spec/#grpcroute](https://gateway-api.sigs.k8s.io/reference/api-spec/main/spec/#grpcroute) Gateway API reference for GRPCRoute
